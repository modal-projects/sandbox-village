# Modal's GPU Glossary

The Markdown files in this folder are an unmodified copy of the `gpu-glossary/` folder of
https://github.com/modal-labs/gpu-glossary at commit 9597497 (Sep 4, 2026).

https://modal.com/gpu-glossary.

Sandbox Village puts these pages on a shelf in Mo's house. It adds one generated file next to
them, `index.json` (the table of contents, in the order of the published glossary), and shows the
pages with their diagrams loaded from Modal's CDN. To update the copy, replace the files here with
the newer ones and change the commit above.
